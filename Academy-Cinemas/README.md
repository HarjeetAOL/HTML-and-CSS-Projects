# Academy Cinemas - Bootstrap one-page website

This project follows the supplied Academy Cinemas Bootstrap tutorial series (Parts 1-12).

## Files

- `index.html` - the complete one-page website.
- `CSS/custom.css` - site colors, typography, navbar, movie cards, tickets, contact area, and footer styles.
- `CSS/custom-css-media.css` - mobile and responsive styling.
- `Images/` - supplied logo, background, movie posters, and star graphic assets.
- `movies.txt` - the supplied movie descriptions reference.

## Open the website

1. Extract the `Academy-Cinemas` folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.

The page loads Bootstrap 5.2.3 and Google Fonts from their CDNs, so an internet connection is required for those external styles and fonts.

The ticket selection and contact form are presentation-only demonstrations, as described by the tutorials. They are not connected to a booking system or email service.
